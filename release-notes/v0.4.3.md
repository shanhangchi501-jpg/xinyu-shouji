# 心屿手记 0.4.3

手记列表不会再跳回顶部了。

## 修复内容

- 从手记列表点开一篇手记，返回后会回到刚才的位置，而不是跳回列表顶部。
- 当前选择的作者筛选也会保留。
- 首页、相处、年轮与「了解」页面的滚动位置同样会保留。
- 在底部标签之间切换后再回来，也会停在原来的位置。

## 适合

- 想一条一条回看很多天以前写下的手记。
- 手记很多、每次都要重新往下翻的情况。

## 安装

要求 Android 8.0（API 26）及以上。

1. 下载 `XinyuShouji-0.4.3-release.apk`。
2. 允许文件管理器或浏览器「安装未知应用」。
3. 打开 APK 安装。

## 从 0.4.2 release 升级

可以直接覆盖安装，数据会保留。
