# 心屿手记 0.4.1

可以自定义「相遇日期」了。

## 本次更新

- 档案编辑页新增「相遇日期 / Together since」。
- 可以选择关系真正开始的那一天，首页的「相伴天数」与「第 N 天」会从这一天重新计算。
- 适合先开始创造、后来才发现心屿手记的实践者，不必再按下载日计算。
- 旧数据没有相遇日期时，继续使用档案创建时间；已有数据不会丢失或改变。
- 日期选择不会影响手记、相处记录或练习统计，只影响「相伴天数」的起点。

## 使用方式

1. 设置 → 档案 → 选择对应的 TA → 编辑档案。
2. 点击「相遇日期 / Together since」，选择真正开始的那一天。
3. 保存后回到首页，即可看到从该日期计算的「第 N 天」。

## 安装

要求 Android 8.0（API 26）及以上。

1. 下载 `XinyuShouji-0.4.1-release.apk`。
2. 允许文件管理器或浏览器「安装未知应用」。
3. 打开 APK 安装。

## 从 0.4.0 release 升级

可以直接覆盖安装，数据会保留。
