# 心屿手记 0.4.2

修复相处计时在应用锁之后丢失的问题。

## 修复内容

- 在相处计时中锁屏，或进入后台超过 30 秒触发应用锁后，解锁不会再回到首页。
- 计时的剩余时间、暂停状态、选择的练习与 TA 都会恢复。
- 计时过程中应用被系统回收或手动关闭，重新打开后也会回到这次练习。
- 如果计时在离开期间结束，回来后会直接显示「这次相处结束了」的记录页。
- 结束页已填写的心情和备注会保留，包括锁定与重新打开之后。
- 计时结束提醒不再因为进入锁屏或切换应用而被取消。

## 说明

- 计时状态和手记一样，保存在本机加密数据中，不会上传。
- 运行中的计时以真实结束时间为准：离开 3 分钟，回来时就会少 3 分钟，不会重新开始。
- 点击「保存这次记录」或「不记录，直接返回」后，进行中的计时状态才会清除。
- 旧数据完全兼容，没有进行中的练习时行为不变。

## 安装

要求 Android 8.0（API 26）及以上。

1. 下载 `XinyuShouji-0.4.2-release.apk`。
2. 允许文件管理器或浏览器「安装未知应用」。
3. 打开 APK 安装。

## 从 0.4.1 release 升级

可以直接覆盖安装，数据会保留。
