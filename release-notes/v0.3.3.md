# 心屿手记 0.3.3

应用更名为「心屿手记」。

## 本次更新

- 启动页、首页、关于、设置、通知与新手引导中的名称统一改为「心屿手记」。
- 包名仍为 `com.innerisle.app`，签名与数据格式不变；已安装 0.3.2 release 版的用户可以直接覆盖升级。
- 重新构建并签名，versionCode 7。

## 安装

要求 Android 8.0（API 26）及以上。

1. 下载 `XinyuShouji-0.3.3-release.apk`。
2. 允许文件管理器或浏览器「安装未知应用」。
3. 打开 APK 安装。

## 从 0.3.2 release 升级

可以直接覆盖安装，数据会保留。

## 从 debug 版迁移

正式版与 debug 版签名不同，不能直接覆盖。请先在旧版「设置 → 数据」导出 JSON，卸载旧版，安装本版后再导入。卸载会删除本地数据。
