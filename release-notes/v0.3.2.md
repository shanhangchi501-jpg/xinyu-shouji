# 心屿手记 0.3.2

首个正式签名版本，面向 GitHub 侧载安装。

## 本次更新

- 新增「从零开始」17 章完整创造指南，覆盖准备、人格设定、叙述、形象、幻境、成声、独立性、日常融合、投影、附体、交换、现实生活平衡与安全求助。
- 文章与概念扩充至 13 篇、24 个词条，并标注证据等级与来源。
- 首页与「了解」双入口，阅读进度保存在本机。
- 首页、年轮数据格子与相处练习格子等高对齐；「成长印记」网格等高并加深配色。
- 修复浅色模式下半透明卡片的矩形色块问题。
- 正式 release 签名；APK 体积从约 20 MB 降至约 14 MB。

## 安装

要求 Android 8.0（API 26）及以上。

1. 下载 `InnerIsle-0.3.2-release.apk`。
2. 在系统设置中允许当前文件管理器/浏览器「安装未知应用」。
3. 打开 APK 安装。
4. 首次启动会显示 18+、非医疗工具与安全提示。

## 从旧 debug 版迁移

正式版使用了新的签名，不能直接覆盖旧 debug 版。请先：

1. 打开旧版 → 设置 → 数据 → 导出 JSON，保存到安全位置。
2. 卸载旧版。
3. 安装正式版。
4. 设置 → 数据 → 导入 JSON。

卸载会删除旧版本地数据，务必先导出。
