# 心屿手记 0.4.0

中英双语版本。

## 本次更新

- 新增完整英文版：启动引导、首页、相处、手记、年轮、了解、指南、文章、概念、设置、关于与通知全部支持英文。
- 英文版包含 17 章「从零开始」指南、13 篇文章、24 个概念词条，以及完整的安全说明与医疗免责声明。
- 首次启动跟随系统语言：英文系统默认 English，其他系统默认中文。
- 设置 → Language 可在「中文 / English」之间切换，切换后应用自动重启。
- 英文日期格式、星期、每日提示、心情选项与成长印记均已本地化。
- 数据格式、包名和签名保持不变；中英文切换不会丢失已有数据。

## 安装

要求 Android 8.0（API 26）及以上。

1. 下载 `XinyuShouji-0.4.0-release.apk`。
2. 允许文件管理器或浏览器「安装未知应用」。
3. 打开 APK 安装。

## 从 0.3.3 release 升级

可以直接覆盖安装，数据会保留。

## 从 debug 版迁移

正式版与 debug 版签名不同，不能直接覆盖。请先在旧版「设置 → 数据」导出 JSON，卸载旧版，安装本版后再导入。卸载会删除本地数据。
